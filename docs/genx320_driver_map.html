GenX320 驅動關係圖

這張圖把之前聊過的東西放進同一個畫面:CPU 特權層級、device tree、driver、DMA、 V4L2 的 subdev 跟 video device,全部怎麼接在一起。

橫軸(左→右)是事件資料實際流過的硬體順序。 縱軸(上→下)是同一顆硬體對應到的軟體層次——最上面是使用者空間的 /dev/... 節點,中間是 kernel 裡的 driver 程式碼, 最下面是 PL 端真正的硬體 IP。

顏色:綠色 = 資料本身在走的路(AXI4-Stream / DMA)。 橘色 = 控制/設定的路(ioctl、暫存器讀寫)。 靛藍 = user mode / kernel mode 的特權層級邊界。
